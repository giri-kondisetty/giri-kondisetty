# Hi, I'm Giri

Security software engineer. I build cloud security software at work, and in my own time I build AI tools that show the evidence behind their answers.

## What I build

- **[Jarvis](https://giri-kondisetty.github.io/jarvis/)**: an AI agent that investigates questions across your systems and shows the evidence behind every claim.
- **[Gateway Inference](https://giri-kondisetty.github.io/gateway/)**: a multi-tenant model API gateway with OpenAI and Anthropic compatible endpoints, API keys, limits and usage and billing per organisation.
- **[Scam Check](https://giri-kondisetty.github.io/scam-check/)**: paste a message or link and it is checked in your browser, with nothing sent or stored. [Source](https://github.com/giri-kondisetty/scam-check).

Behind Jarvis are MCP connectors to cloud, data, identity, security and business platforms, and a sandbox that reproduces findings safely. Those repositories are private.
